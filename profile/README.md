<h3 align="center">Stop tab-hunting your agents.</h3>

<p align="center">
  <b>Overterm</b> is a macOS terminal built for running several agents at once — Claude Code, Codex —<br/>
  each in its own worktree, with a window that tells you which one needs you.<br/>
  Native AppKit around <a href="https://github.com/ghostty-org/ghostty">libghostty</a>: your Ghostty config applies as it is.
</p>

<p align="center">
  <a href="https://github.com/Overcraft-hq/overterm"><img alt="The Overterm window" src="https://raw.githubusercontent.com/Overcraft-hq/overterm/main/docs/assets/screenshot-window.png" width="860"></a>
</p>
